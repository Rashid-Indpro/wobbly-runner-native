# Company Intro Video

## Required Video File

Place your company introduction video here with the name:
**`company-intro.mp4`**

## Video Specifications

### Recommended Settings:
- **Format**: MP4 (H.264 codec)
- **Duration**: 3-5 seconds (keep it short and engaging)
- **Resolution**: 1080x1920 (portrait) or 1920x1080 (landscape)
- **File Size**: < 5MB for optimal app performance
- **Audio**: Optional (video will play with sound if included)

### Tips:
- Keep the video short (3-5 seconds) for better user experience
- Use dark background (#111111) to match app theme
- Ensure the video shows "InteraMinds" branding clearly
- Test on both iOS and Android devices

### File Location:
```
assets/
  └── videos/
      └── company-intro.mp4  ← Place your video here
```

## How It Works

1. Video plays automatically when app launches
2. Plays once (no looping)
3. Automatically transitions to splash screen when finished
4. Dark background (#111111) displays if video fails to load
